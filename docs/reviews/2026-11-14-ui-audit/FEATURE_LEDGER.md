# UI feature and flow ledger — 14 November 2026

> Historical 14 November scope. The [current full-feature packet](README.md) supersedes feature exclusions, read-only-only management and Classic fallback as a final destination. Original defect evidence remains valid.


Status: proposed work for review; no implementation is claimed. This ledger inventories every control or informational region in the custom Task and Workspace pages, plus native entry points and Classic surface families. Rows group controls only when their behavior and acceptance contract are shared.

Evidence is source inspection of the current checkout. The existing test-summary parser was executed in isolation against synthetic strings. No real gateway sessions, prompts, interruptions, Git mutations, PRs, dialogs or native lifecycle actions were exercised for this ledger. Classic entries establish bundle/bridge family coverage, not live verification of every compiled control. Timing-dependent races and platform-dependent behavior are identified as risks. Source line links describe the audit snapshot and may move during implementation.

Phase ownership: **N** native reliability; **U1** state, transport feedback and composer; **U2** layout, navigation and accessibility; **U3** complete transcript and run evidence; **U4** repository review and reviewed actions; **V** verification and documentation; **D** deferred. “Initial” means part of the proposed initial implementation, not completed. Classic initial scope is limited to explicit bridge refusals, one shared visible unsupported-operation/error diagnostic, and capability flags the unchanged generated bundle already consumes. It does not include per-screen hiding/disabling, state integration, or reviewed mutation UX in Classic. Those changes remain deferred; U1–U4 reviewed UI behavior applies to custom Task/Workspace only.

Proposed product contract: Task is primary; Workspace remains an explicit repository review surface; Classic is an explicit fallback. Sessions are unique and searchable. Scheduled jobs offer read-only inspection. “Agents used” and “Tools used” describe this session's recorded evidence. Remove the fake Inbox. Use Chat / Split / Changes modes. At **≥1600px**, an inspector may dock; at **1280–1599px**, it is a side drawer; at **≤1279px**, show one main Chat or Changes view and a 56px icon rail with named controls/tooltips and a searchable session drawer. Call transcript-derived shell output **Command output**, reserving **Terminal** for an actual PTY. **Add file reference** explicitly adds local path references initially; hide the misleading image-specific button. Multimodal uploads remain deferred until the gateway schema is verified. The @ control searches the chosen repository. Errors stay visible; stale and unknown states are honest. Custom Task/Workspace discard and PR creation require a concrete review before execution; equivalent Classic screen changes remain deferred.

All acceptance criteria below describe future fixture-based verification. Mutation criteria use disposable repositories and mocked transports, never the user's working tree or real gateway.
